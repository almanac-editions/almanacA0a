The formal layer

Nine of this edition’s twelve results carry a proof-kernel certificate. This page is what that means, row by row, assembled from CONCORDANCE.json and the release log — it states no fact those files do not.

What the kernel said

release_verify --source: ALL CLEAN (source rebuild + verifier + clean-triple axioms)

Quoted from the release log, which is the artifact the certification cites. A result counts as kernel-certified only when its axiom base is exactly propext, Classical.choice, Quot.sound: the three standard axioms of Lean's kernel — propositional extensionality, the axiom of choice and quotient soundness — the base every Mathlib proof shares; a certificate is clean when these three are all it needs — with no sorryAx and no custom axiom.

What a certificate does not say

The kernel certifies the formal statement. Whether that statement is faithful to the informal one is a separate question, and this edition answers it separately — see the embedding note, and the one ink-warranted row in the concordance.
